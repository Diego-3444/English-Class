# World Tour — The English Adventure

Videojuego de mesa para practicar inglés. Proyecto de clase, 2026-09-10.

## Cómo jugar

Doble clic en **`index.html`**. Abre en el navegador, funciona offline, no necesita instalar nada.

En Chrome, `⌃⌘F` para pantalla completa. Escribe los nombres antes de darle a *Start the tour*.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | El juego completo (interfaz, estilos y lógica) |
| `cards.js` | Las 46 cartas y el layout del tablero — **aquí se edita el contenido** |
| `WRITTEN-COMPONENT.md` | Documento de 300 palabras que pide la rúbrica |
| `PRESENTATION-SCRIPT.md` | Guion de presentación de ~6 min para 4 personas |
